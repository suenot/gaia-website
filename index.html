Google AI Automation

Automate Google's creative AI.
No API keys.

GAIA drives Gemini, Flow and NotebookLM through your own logged-in session to generate text, images, video, music, slides and podcasts.

View on GitHub Quick start

What it drives

Gemini

Text to image, image to video and text to video with Veo.

Flow

Veo film clips in a Flow project: Nano Banana edits, Veo 3 and the Omni agent.

NotebookLM

Create notebooks, add or discover sources, then download Audio Overviews and Slide Decks in any language.

Music

Gemini "Create music" and Labs MusicFX. Experimental.

YouTube Studio

Upload with title, description, tags and thumbnail. No Data API, private by default.

Stable session

Persistent Camoufox profile with a pinned fingerprint. Your Firefox login is never touched again.

The Content Factory

GAIA is stage 1 of a pipeline that turns a blog article into a published YouTube video.

  1. 1

    Generate

    gaia — NotebookLM, Gemini and Flow produce audio overview and slide deck.

  2. 2

    Build

    video-maker — narration and slides become a synced MP4 with SRT and thumbnail.

  3. 3

    Describe

    video-metadata — title, description, tags and chapter timestamps.

  4. 4

    Publish

    video-publisher — upload to YouTube Studio with metadata and visibility.

Get started

Python 3.11–3.13 (not 3.14).

git clone https://github.com/suenot/gaia.git && cd gaia
python3.11 -m venv venv && source venv/bin/activate
pip install -r requirements.txt
python3 -m camoufox fetch
python3 login_camoufox.py --bootstrap

python3 gemini_image_gen.py --prompt "a red fox in deep snow, cinematic, 16:9"
